

Meldebogeneingabe
=================

Aktuell gibt es bewusst keine "echte" Anmeldung - die Authentifizierung erfolgt über Mitgliedsnummer + Passwort für
die Meldebogeneingabe. Es wird für neue Meldebögen neue Passwörter geben - zumindest solange es noch kein echtes 
Mitglieder Portal gibt.

Sobald der Meldebogen im letzten Schritt mit "verbindlich absenden" abgeschickt wird, wird er für die Admin-Interface User im Mitgliedskonto sichtbar.
Momentan ist der Bogen danach immer noch bearbeitbar das könnte man aber ggf. noch sperren.

Die Informationen werden auf der letzten Seite nochmal final zusammengefasst dargestellt und können als PDF für die eigenen Unterlagen heruntergeladen werden.
